AlterEgo Finder

Drop a face photo, and it finds the ten closest public figures, each labelled Same person, Alter Ego or Not You.

For anyone curious who they resemble, and for data scientists who want to know how much to believe the answer: the labels come from thresholds calibrated on held-out strangers.

Your photo never leaves your machine.

An LFW photo of Lennox Lewis against the pool of 500 public figures. Distance from the centre is exactly one minus the score; direction means nothing.

Try it locally

git clone https://github.com/esst-prog2/AlterEgo_Finder
cd AlterEgo_Finder
python -m venv .venv
.venv\Scripts\activate   # macOS or Linux: source .venv/bin/activate
pip install -r requirements-ui.txt
python setup_data.py     # about 3.5 minutes
streamlit run app.py

Then open http://localhost:8501 and drop a photo. Python 3.10 or newer, about 750 MB of disk. All steps, and the public-figure pool.

How it works

A face is detected, turned into a fingerprint of 512 numbers, and compared with every face in a dataset by cosine similarity: 500 faces from LFW by default, or the optional pool of 500 public figures.

Two thresholds turn each score into a label. The upper one, for Same person, is fitted to the best matches of strangers who are not in the dataset, at the dataset's size, so a bigger dataset gets a higher bar. The lower one, between Alter Ego and Not You, is the equal-error-rate point: as many same-person pairs fall below it as different-person pairs rise above it, in proportion.

  1. DetectYuNet finds the largest face, and turns the photo first if it is on its side or upside down.
  2. FingerprintArcFace turns the aligned face into 512 numbers.
  3. CompareOne matrix multiplication scores it against every face in the dataset.
  4. LabelThe calibrated thresholds name each of the ten closest.

Privacy

Everything runs on your computer. Your photo goes only to a server on your own machine, served on localhost; there is no account, and nothing about you is sent anywhere.

Setup downloads data and models: the LFW faces, the two model files, and, if you ask for it, the pool's photos from Wikimedia Commons. The pool is limited to adults known to the public, with no politicians, and every photo's author and licence are credited in the program and its reports.

Run it at home

  1. You need Python 3.10 or newer and about 750 MB of disk. Create a virtual environment in a clone of the repository:python -m venv .venv .venv\Scripts\activate
  2. Install and set up the default dataset, 500 LFW faces (about 3.5 minutes):pip install -r requirements-ui.txt python setup_data.py
  3. Start the page and open http://localhost:8501:streamlit run app.py
  4. Optional, the public-figure pool (about 30 minutes, resumable), then choose wikidata in the page's dropdown:python setup_data.py --wikidata

On Windows, if a library is blocked by Smart App Control or a managed PC's policy, see the README's getting started section.

Limits

Written the way a model card is, because the limits are part of the answer.

Intended use
Finding the closest public figures to a face, with a calibrated label, on your own machine.
Out-of-scope use
Identifying people, or any decision about a person.
Evaluation data
LFW for calibration and tests; 500 Wikimedia Commons photos for the pool.
Metrics
The scorecard above.
Limitations
  • Alter Ego means the closest public figure in this pool, and not you. It is not a striking likeness: 97% of strangers' best matches land there.
  • The pool's thresholds are fitted with LFW faces as the strangers, while its photos come from Wikimedia Commons, so its labels are a little less exact than LFW's.
  • At these low scores, a match can cross gender.
  • Faces tilted by about 45 degrees still match poorly. One photo per person in the pool.
  • Each Same person is evidence, not proof of identity.
