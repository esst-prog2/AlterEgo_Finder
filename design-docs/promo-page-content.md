## Problem Statement

Homework 9 asks for a promo page on GitHub Pages that says what AlterEgo Finder is for, who it is for and how to try it, due Saturday 14 November 20:00. Nothing personal may go on the page, and GitHub Pages publishes everything in the page's folder. The program runs only on the user's own computer, so the page cannot link to a live version: "how to try it" means running it locally.

## What Makes This Cool

Most lookalike apps always name someone. This one says *Not You* when it should, and it can show how it knows: predictions written down before several of its runs, held-out strangers, a spike whose decision rule said no, and a fix measured from 0 to 148 of 150. Where a committed command exists, the page lets a reader check the number on their own machine, not just read it.

## Approaches Considered

### Approach A: One honest page
Minimal single page with short receipt cards. Ruled out: the receipts are told without their sources, dated predictions or failures side by side.

### Approach B: The receipts ledger (chosen)
A's page plus a sourced ledger: each claim with its dataset, the prediction written before the run where one is logged, the measured result, failures included, and a command only where one reproduces the number on a fresh clone. Model-card limits.

## Recommended Approach

Approach B. One static page, sections in this order, with draft text below. Wording is a first draft for the design step to tighten; every number is already checked against PLANNING_LOG.md.

**1. Hero**
- Title: AlterEgo Finder
- Line 1 (what): Drop a face photo, and it finds the ten closest public figures, each labelled *Same person*, *Alter Ego* or *Not You*.
- Line 2 (who and why): For anyone curious who they resemble, and for data scientists who want to know how much to believe the answer: the labels come from thresholds calibrated on held-out strangers.
- Line 3: Your photo never leaves your machine.
- Call to action: Try it locally (jumps to section 5).

**2. How it works** (one short paragraph and a figure)
A face is detected (YuNet), turned into a 512-number fingerprint (ArcFace), and compared with every face in a dataset by cosine similarity: 500 LFW faces by default, or the optional pool of 500 public figures. Two thresholds split the scores into the three labels. The upper one, for *Same person*, is fitted to strangers' best matches at the dataset's size, so a bigger dataset gets a higher bar. The lower one is the point where pairs of photos of the same person and of different people are equally likely to be confused. Figure: the similarity target for an LFW example, where distance from the centre is exactly one minus the score, with the threshold rings.

**3. The receipts** (the main body: a ledger, one row per claim, failures included)

Rules for the ledger:
- The "Written before the run" cell quotes or closely paraphrases a PLANNING_LOG.md line dated before the result. Where there is none, it says "none logged", and the page does not claim one.
- The "Check it" cell holds a committed command only when that command, run on a fresh clone as written, gives the number. Otherwise it says "record only" and names the committed record. Only rows with a command are presented as checkable.
- Each row names its dataset: LFW (the default setup) or the public-figure pool (the optional step).

**4. Privacy** (short)
Everything runs on your computer, served on localhost only. There is no account and no upload. The public-figure pool is fetched once from Wikimedia Commons, with each photo's author and licence credited, and limited to adults known to the public, with no politicians.

**5. Try it locally**
```
git clone https://github.com/esst-prog2/AlterEgo_Finder
cd AlterEgo_Finder
pip install -r requirements-ui.txt
python setup_data.py            # about 3.5 minutes: LFW, datasets, calibration
streamlit run app.py
```
Then open http://localhost:8501, keep the default dataset (500 LFW faces), and drop a photo.

Optional, for the public-figure pool: `python setup_data.py --wikidata` (about 30 minutes, rate-limited downloads from Wikimedia Commons, resumable), then choose `wikidata` in the page's dropdown. The pool's rows in the receipts come from this dataset. (Exact commands to be checked against README section 6 before publishing.)

**6. Limits** (model-card headings)
- *Intended use:* finding the closest public figures to a face, with a calibrated label, on your own machine.
- *Out-of-scope use:* identifying people; any decision about a person.
- *Evaluation data:* LFW for calibration and tests; 500 Wikimedia Commons photos for the pool.
- *Metrics:* the ledger above.
- *Limitations:* *Alter Ego* means "the closest public figure, and not you", not a striking likeness (97% of strangers land there). Tilts near 45 degrees stay poor. One photo per person. Each claim of *Same person* is evidence, not proof of identity.

**7. Footer**
Course project, ELTE Advanced Programming 2026/27. Source on GitHub. Photo credits for the pool are in the program and its reports.
